# Common mistakes

- **Mapping indexes to the new alphabetical order.** `lot_slot[0]` is not `A1`. The old list started with `C3`. A moved block for random_integer with the wrong key plans cleanly and silently hands block A1 the number that belonged to C3.
- **Applying first "to see what happens".** Twenty destroy-and-create pairs on a live auction house regenerate the licence and every dashboard slot number.
- **Reverting the refactor to `count`.** It makes the plan clean, but it throws away a merged review and the validator rejects count.
- **Fixing it with 20 `terraform state mv` commands under pressure.** It works once, but nobody else's workspace benefits and the next environment (staging, DR) breaks the same way. The mission asks for declarative moved blocks.
- **Forgetting the two singletons.** `ops_licence` and `go_live` were renamed too; leaving them out shows up as a replaced licence.
